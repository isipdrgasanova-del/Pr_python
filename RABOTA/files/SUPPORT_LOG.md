## Детали обращений

### Issue #8 — Баг: отрицательный год принимается

**Репортер:** тестировщик (внешний)  
**Шаги:**
1. `python main.py` → пункт 1 (Добавить книгу)
2. Название: `Тест`, Автор: `А`, Год: `-100`
3. Книга добавляется без ошибки — **ожидалось сообщение об ошибке**

**Исправление:** в функции `_validate_book` условие:
```python
# было:
if not (y < 0 or y <= current_year):
# стало:
if not (0 < y <= current_year):
```

**Регрессионный тест:** `test_regression_negative_year_raises`

---

### Issue #9 — Баг: фильтр «читаю» не работает

**Репортер:** другая команда  
**Шаги:**
1. Добавить книгу со статусом `читаю`
2. Меню → Фильтрация → По статусу → `читаю`
3. Результат: `Книги не найдены` — **ожидалось 1 совпадение**

**Исправление:** добавлен `.strip()` при сравнении статуса в `filter_by_status`.  
**Регрессионный тест:** `test_regression_filter_by_status_reading`

---

### Issue #10 — Улучшение: сортировка по дате добавления

**Запрос:** добавить возможность сортировки по дате добавления книги.  
**Ответ:** поле `added_at` уже сохраняется для каждой книги с версии 1.0.0.  
Сортировка через фильтры планируется в версии 1.1.0.

---

### Issue #11 — Изменение поведения: подтверждение удаления

**Запрос:** перед удалением книги просить подтверждение, чтобы избежать случайного удаления.  
**Реализация:** в `menu_delete()` добавлен интерактивный запрос:
```
Удалить? (да/нет):
```
Удаление происходит только при вводе `да`.

### Issue #12 — Вопрос: как посмотреть все прочитанные книги?

**Вопрос:** «Как отфильтровать только прочитанные книги?»  
**Ответ:** Меню → `4. Фильтрация` → `1. По статусу` → ввести `прочитано`.  
Описание добавлено в README.md, раздел «Возможности».
