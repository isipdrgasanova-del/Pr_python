# 📚 Библиотека книг

Консольное приложение для учёта личной библиотеки.  
Версия: **1.0.2**

---

## Возможности

- Добавление книг (название, автор, год, жанр, статус)
- Просмотр всего списка
- Поиск по названию или автору
- Фильтрация по статусу, жанру, году
- Редактирование и удаление записей
- Статистика (всего, по статусам, по жанрам)
- Хранение в CSV-файле (`books.csv`)

---

## Требования

- Python 3.10+
- `pytest`, `pytest-cov` (для тестирования)

Установка зависимостей:
```bash
pip install pytest pytest-cov
```

---

## Запуск

```bash
python main.py
```

---

## Тестирование

```bash
pytest tests/ -v --cov=library
```

Ожидаемый результат: **52 теста, покрытие 100%**.

### Структура записи книги

| Поле       | Тип    | Описание                              |
|------------|--------|---------------------------------------|
| id         | int    | Уникальный идентификатор              |
| title      | str    | Название книги                        |
| author     | str    | Автор                                 |
| year       | int    | Год издания (1–текущий год)           |
| genre      | str    | Жанр (необязательно)                  |
| status     | str    | `прочитано` / `не прочитано` / `читаю`|
| added_at   | date   | Дата добавления (YYYY-MM-DD)          |
